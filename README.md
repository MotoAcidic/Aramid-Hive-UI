# Aramid-Hive-UI

This repository contains the web UI for the Aramid-Hive-Engine backend framework. The backend framework can be found at the following URL:

[Aramid-Hive-Engine](https://github.com/MotoAcidic/Aramid-Hive-Engine)

## Overview

The Aramid-Hive-UI provides a user-friendly interface to interact with the backend API. It includes features such as:

- Task description input
- AI text generation
- Research and summarization
- Agent chat responses

## Setup

To set up the web UI, follow these steps:

1. Clone this repository.
2. Install the necessary dependencies.
3. Configure the API URL in `public/app.mjs`.
4. Serve the static files using a web server.

## Usage

Once set up, you can use the web UI to interact with the backend API by entering tasks or questions and receiving responses from the AI agents.

For more details on the backend framework, visit the [Aramid-Hive-Engine](https://github.com/MotoAcidic/Aramid-Hive-Engine) repository.
